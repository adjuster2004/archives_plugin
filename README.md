# archives_plugin
Plugin for Archives

## Плагин для загрузки листов из архивов

Добавлено
- Поддержка Рязанского архива
- Поддержка Владимиского архива vladimir.kaisa.ru. Начиная с версии 2.0 абсолютно иной подход!!!

## 🛠️ Последовательность
- **Склонировать репозиторий**
```bash
git clone https://github.com/adjuster2004/archives_plugin/
```

- **Добавить плагин в браузере**

Требуется включить режим разработчика

```
chrome://extensions/
```
